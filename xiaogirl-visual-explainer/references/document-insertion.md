# 按文档格式插图

通则：使用当前环境实际可用的文档工具，读取其要求。保留原文、表格、章节、链接和既有视觉风格；在原文锚点后回插。图标题在图内已有时，不再加重复红色标题。必要图注用简短中性色文字。默认交付新版本；不擅自公开发布源文件。

| 输入 | 回插策略 | 必须验证 |
| --- | --- | --- |
| DOCX | 按标题+原文段落定位，在段落后嵌入图片；不把整篇转换为图片；保留样式和链接 | 分页、图片宽度、表格、段落顺序；导出预览核对 |
| PPTX | 使用原页空白区；空间不足时在原页之后新增一张解释页并继承模板 | 16:9/4:3等原页比例、页序、文字溢出、图片覆盖 |
| HTML | 在相应章节容器内插入figure与alt；单文件离线交付时内嵌图片并避免依赖远程加载正文 | 本地直接打开、移动端、锚点/链接、控制台错误、图片加载 |
| Markdown | 在锚点后插入图片链接，相对路径随资产一起交付；需要单文件可另交付内嵌图HTML | 链接目标存在、渲染正常、标题结构不乱 |
| PDF | 优先修改可编辑源文件再导出PDF；仅有PDF时，在相关页之后插入解释页并保留原页 | 新旧页映射、页尺寸、原文未遮盖、内部链接及书签需检查 |
| 在线文档 | 有已连接且可编辑工具时建立副本后插入；仅能读取时生成本地带图版本并说明未改线上原件 | 读取回插结果，检查分享/访问状态，不自动扩大权限 |
| 纯文字/聊天 | 默认组织成可直接打开的带图HTML文档副本；用户指定Word/PPT等则按要求交付 | 正文完整、图文顺序、资源内嵌、可下载打开 |

## 清晰度

- 按实际容器宽度和阅读字号设计；图片高度随比例变化。HTML设max-width:100%、height:auto，并限制桌面展示宽度，避免把低分辨率图放满超宽屏。
- 数字、图线与文字优先保留矢量/可编辑层；栅格图按实际输出尺寸生成。原图低清时缩小显示或重新生成，不把插值放大称为真高清。
- 不裁切标题、人物、箭头或解释内容。手机正文过密时分段重排；新增张数若超出用户确认范围，先说明。

## 重复执行与定位

使用文档版本、章节标题、原文短引文和候选ID定位。HTML/Markdown可写入不影响阅读的生成标记；DOCX/PPT/PDF在任务状态文件记录图片和目标位置。已经成功插入的同一候选默认跳过，明确要求替换时才更新。

## 工具边界

Skill定义操作流程，不能自行授予文件写入、生图、PPT/PDF编辑或视频渲染权限。任务开始检查实际能力；缺少回插工具时提供图片与精确插入位置，明确尚未完成文档回插，不虚构可点击的下载链接。部署或覆盖在线原件仅在已有用户授权范围内执行。
