# 手绘小女孩视频与网页动效

## 推荐 6 镜头模板

1. **标题出现**：黑色手写标题逐笔写出，橙色下划线随后划过。
2. **角色进入**：小女孩从画面边缘探身或走入，动作幅度小，保持手绘线稿。
3. **概念出现**：一个物件、卡片或 K 线从白纸上浮现，不要出现霓虹 HUD。
4. **关系建立**：橙色箭头从输入指向输出，线条逐步绘制。
5. **结论强调**：蓝色标签或红色警示轻微弹出，突出一句短结论。
6. **收束**：底部记忆点和角色动作停留 1–2 秒，方便截图和阅读。

## 可用动效

- SVG `stroke-dasharray` / `stroke-dashoffset` 绘制箭头、路径和 K 线。
- CSS `transform` 做 2–4px 的角色呼吸、纸张轻摆和卡片入场。
- IntersectionObserver 触发网页卡片依次出现。
- Canvas/Remotion 只用于粒子、轻微纸屑或数据点；背景仍保持干净白底。
- `prefers-reduced-motion: reduce` 时关闭移动、粒子和循环动画。

## 禁止

- 不把手绘插图整体套成赛博霓虹滤镜。
- 不让人物随机换脸、换发色或换制服。
- 不用动画替代逐字准确的日期、金额、奖项和规则字幕。
- 不为“酷炫”加入无意义粒子、扫描线、网格或漂浮符号。
