# 赛事女孩配图 QA

## 必过项

- 是 16:9 横版正文配图，或明确标注为单人资产。
- 背景是干净纯白，不能有蓝色摄影背景、光晕、渐变、纸纹或阴影。
- 出现同一赛事女孩：黑长发、蓝眼睛、白色高领服装、深蓝结构线、青色肩部徽章。
- 女孩承担观察、记录、筛选、检查、引导、连接或修补等核心动作。
- 黑色手绘线稿清楚，线条略有手绘感，颜色克制。
- 画面保留约 20%-35% 留白，标题、区块和箭头之间有清楚的呼吸空间。
- 一张图只讲一个核心结构，包含一个可读标题和 3–6 个区块或步骤。
- 每个区块都有与角色/物件对应的短标签和一行简洁解释；箭头、下划线或连线真正表达顺序、因果或分工。
- 中英文文字清楚、简洁、可读；固定文案没有被模型擅自改写；不能出现乱码、假字或伪文字。
- 没有小黑、其他 IP、PPT 网格、正式流程图和左上角类型标题。
- 没有模型伪造的官方 Logo、二维码、赛事日期、奖项金额或真实证券数据。

## 失败信号

- 人物变成棕发、黑眼或普通制服，无法与赛事 IP 识别。
- 背景重新出现主 KV 的蓝色光效和科技城市。
- 女孩只是站在一旁，画面核心动作由道具独立完成。
- 画面像海报、课程页、App 截图或信息图。
- 标题缺失，或画面只有角色和物件却没有可读文字。
- 中文错字多、数字不可靠、证券名称不可辨认。
- 英文拼写错误、标签过长或文字挤压主体。
- 文字太小、区块超过 6 个、或短说明变成长段正文。
- 文字与图形脱节，读者无法看出步骤之间的关系。
- 画面用随机符号填充，假装是中文或英文。
- 手部、脚部、肩部徽章或服装结构明显变形。

## 迭代方法

- 人物漂移：重新使用 canonical 参考，减少场景元素，先生成单人再合成场景。
- 太像海报：删除光效、背景和大标题，保留白底和一个动作。
- 太像 PPT：去掉边框、网格、节点和长文字，换成一个低科技物理隐喻。
- 角色不参与：把女孩改成正在记录、拉动、检查、递交或修复核心物件。
- 文字缺失：重新生成，使用“标题 + 3–6 个固定文本块 + 橙色箭头/下划线”的文字优先提示词。
- 文字出错：减少区块数量，提供逐字固定的标题和短说明；仍无法保证时，保留清晰排版区域并单独叠加文字层。
- 画面过满：优先保留标题、3 个最重要步骤和结论，删除次要解释，不牺牲可读性。
